        Voice behind the hologram

        Use ChatGPT for conversation while this page displays Joi. This mode makes no OpenAI API calls. ChatGPT plan limits still apply.

        1. Open the ChatGPT app. In Settings → Voice, enable Background conversations. The setting’s location can vary by app version.
        2. Start Voice in a chat. Tap the Voice icon and choose a voice you like. You can ask: “Call yourself Joi. Speak warmly and calmly, keep replies practical, and help me organize my day.”
        3. Return to this Joi page in Chrome. Keep the ChatGPT voice session running in the background. End the call from ChatGPT when you finish.
